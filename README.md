
# JMT Producciones — Event Production Website

Professional corporate website developed for **JMT Producciones**, an event production company based in Posadas, Misiones, Argentina, specializing in professional sound systems, lighting, and audiovisual solutions for private, social, and corporate events.

🌐 **Live Website:** https://jmtproducciones.com.ar/

## 📌 About the Project

A responsive business website designed to showcase JMT Producciones' services, equipment, and technical capabilities while generating new customer inquiries.

The project focuses on combining modern UI design, performance optimization, and a comprehensive SEO strategy to improve the company's visibility in local search results.

## 🚀 Main Features

- Modern and responsive user interface.
- Service-focused landing pages and detailed service information.
- Interactive navigation with React Router.
- Equipment and professional audio brand showcase.
- WhatsApp integration for direct customer inquiries.
- Contact and lead generation sections.
- Responsive image galleries and multimedia content.
- Optimized navigation and mobile user experience.

## 🔍 SEO & Search Engine Optimization

A strong focus was placed on technical SEO and local search visibility.

- Dynamic page metadata using React Helmet Async.
- Custom SEO titles and meta descriptions.
- Service-specific content targeting relevant search queries.
- Local SEO strategy focused on Posadas and Misiones, Argentina.
- Semantic HTML structure and heading hierarchy.
- Open Graph metadata for social media sharing.
- Canonical URLs to help prevent duplicate content issues.
- XML sitemap configuration.
- Robots.txt configuration.
- Search-friendly URLs and internal linking.
- Image optimization and descriptive alternative text.
- Structured data implementation to support search engine understanding.

## 🎧 Services

- **Development:** HTML5, CSS3, Git, GitHub
